# Axiom — Autonomous AI Agent Platform ⚡🤖

A futuristic, high-performance landing page for an autonomous AI agent orchestration platform, built with **Next.js 16**, **React 19**, **React Three Fiber (R3F)**, **GSAP**, and **Tailwind CSS 4**.

## ✨ Key Features

- **Interactive 3D Hero Canvas**: Procedural WebGL particles and geometry rendered using `@react-three/fiber` and `@react-three/drei`.
- **Live Agent Simulation Console**: Interactive interactive console showing mock multi-agent task execution and status telemetry.
- **Glassmorphism Design**: Frosted glass navigation with theme switching (Dark & Light modes).
- **Smooth Inertial Scrolling**: Powered by [Lenis](https://lenis.darkroom.engineering/).
- **Kinetic Animations**: Micro-interactions, word-by-word reveal effects, and fluid transitions using [Framer Motion](https://www.framer.com/motion/) and [GSAP](https://gsap.com/).
- **Component Showcase**: 3D Bento Grid, Workflow Timeline, Pricing Calculator, FAQ Accordions, and Marquee ticker.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router + Turbopack)
- **Library**: [React 19](https://react.dev/)
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Motion & Styling**: Tailwind CSS 4, Framer Motion, GSAP, Lenis
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.17+ or v20+)
- npm / pnpm / yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Aanandswarup/axiom-ai-platform.git
   cd axiom-ai-platform
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
